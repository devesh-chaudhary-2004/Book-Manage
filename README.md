📚 Book Management System

A simple and efficient Book Management System that allows users to manage books, track records, and perform operations like adding, updating, deleting, and viewing books.

🚀 Features
➕ Add new books
📖 View all books
✏️ Update book details
❌ Delete books
🔍 Search books by title/author
📊 Organized and user-friendly interface
🛠️ Tech Stack
Frontend: HTML, CSS, React
Backend: Springboot
Database: MongoDB
